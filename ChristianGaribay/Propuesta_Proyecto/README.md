# Propuesta de Proyecto

**Plataforma:** iOS (Swift)  
**Autor:** Christian Eduardo Garibay Herrera  

## Descripción General

Mi proyecto se basa en una aplicacion móvil de venta a base de creación de modelos 3D de ramos de flores 
de limpia pipas los cuales al terminar de diseñar un ramo, con un boton se puede mandar a pedir el ramo a domicilio.

## Organizacion de pantallas

Para garantizar un programa facil de entender para el usuario se optara por las siguientes pantallas

1. Login: Una pantalla de login para las cuentas de los usuarios
2. Pantalla de inicio: Pantalla donde se mostraran opciones basicas como "Crear nuevo ramo", "Ver Catalogo", "Likes", "Diseños anteriores", "Carrito", etc. En esta tambien se mostrara los diseños mas recientes y adquiridos por otros usuarios.
3. Catalogo: Una pantalla donde se enseñaran las creaciones de nuestra mano de obra o diseños de la misma comunidad de la aplicacion
4. Creacion de Ramo: Pantalla donde se mostrara una especie de lienzo en blanco donde se podran ir agregando las partes del ramo a partir de herramientas de creacion de modelos 3D, en esta pestaña se mostrara una barra de materiales y formas predeterminadas para que se puedan ir agregando al lienzo, tambien tendra una barra de herramientas basicas como "borrar", "Regresar un elemento", "Cambiar color", etc. Tambien se incluira un sub menu desplazable donde se mosraran las opciones de guardado la realizacion del pedido del ramo.
5. Carrito: Esta pantalla mostrara una lista con los ramos que el cliente selecciono para ralizar un pedido, en esta pantalla se podran seleccionar cuales ramos se desean comprar y dejar sin seleccionar los que se quieran para un pedido posterior, esta ventana tambien contara con una funcion de desechado de diseños despues de un periodo de tiempo.
6. Ventana de Realizacion de la compra: En esta ventana se seleccionara todo lo relacionado con la compra, tanto los datos de metodo de pago, datos de usuario(Nombre, Direccion, Telefono, etc), Numero de pedido, Seleccion de cantidad de ramos y seleccion del plazo de entrega.
Ventana likes: Esta ventana esta destinada a guardar los diseños que el usuario les alla dado like para una posterior compra, a comparacion del carrito en esta ventana guardara permanentemente los diseños a los que se les alla dado like
7. Diseños anteriores: En esta ventana se mostraran las creaciones que tu mismo has hecho para editarlos nuevamente, volver a comprarlos o borrarlos, 
8. Configuracion: Esta ventana mostrara las opciones de configuracion de la aplicacion e informacion de usuario como: Cerrar sesion, Cambio de cuenta, cambio de contraseña, Preguntas frecuentes, Politicas de seguridad, etc.
